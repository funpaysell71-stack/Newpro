# Website Agent Team

Three roles: Designer, Developer, QA. This is not LEADATLAS.

## Workflow
Designer specifies design → Developer builds website → QA checks and sends defects back → human approves deployment.

## Files
- `.github/agents/designer.md`
- `.github/agents/developer.md`
- `.github/agents/qa.md`
- `AGENTS.md`
- `.github/workflows/quality.yml`

## Status
Role instructions and GitHub Actions quality checks are installed. **The agents are not yet autonomous.** For automatic AI generation we must add an orchestrator, API credentials, and a secure execution environment. Do not commit secrets.

# Website agent team

Workflow: Designer → Developer → QA. If QA rejects, Developer revises and QA checks again. Human approval required before deploying.

Designer: .github/agents/designer.md
Developer: .github/agents/developer.md
QA: .github/agents/qa.md

Agents are role definitions, not autonomous running services. To run the team, configure an orchestrator and provider API credentials. Never commit API keys.

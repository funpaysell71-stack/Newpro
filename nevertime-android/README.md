# Nevertime Client Android

Independent Minecraft Bedrock companion app, not affiliated with Flarial. Android 12L+.

Includes native dark UI, floating draggable HUD with live device clock, permission controls, Minecraft launcher.
Does not hook Minecraft rendering or display game FPS/coordinates. This is not yet feature-equivalent to Flarial.

Build: GitHub Actions → Build Nevertime Client APK → Run workflow → download Nevertime-Client-APK artifact. Device and build verification pending.

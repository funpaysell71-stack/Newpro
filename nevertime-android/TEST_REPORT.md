# Проверка Nevertime Client 0.2

Дата: 25.10.2026. Реальный телефон и установленный Minecraft в среде разработки отсутствуют.

## Уже выполнено локально

- JDK 17 + Gradle 8.9 + Android SDK 35 / Build Tools 35.0.0: `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug` — **BUILD SUCCESSFUL**.
- Сборка основного APK и отдельного instrumentation APK выполнена. APK Signature Scheme v2 и состав встроенного .mcpack проверены перед выдачей.
- 11 JVM assertions: ограничение значений, относительные позиции, слишком большой виджет, отрицательные координаты, NaN, формат времени — успешно.
- 4 Node test cases: восстановление/валидация preferences, часы мира, направления, координаты/скорость/полное отключение HUD — успешно.
- Lint ранее обнаружил 4 ошибки: Rect.inset API 31, theme attribute API 27 и два некорректных Typeface constants. Все исправлены; новая проверка проходит. Для русского текста, физических координат окон и drag-only touch listener есть локальные пояснённые подавления предупреждений; ошибки API не подавлялись.

## Android instrumentation

Добавлен тест без внешних тестовых библиотек: запуск Activity, навигация четырёх вкладок, отсутствие Minecraft, сохранение/применение профиля, отклонение повреждённого профиля без частичных изменений, границы позиций, запуск/блокировка/остановка foreground HUD, отказ запуска без модулей. Workflow запускает его на Android API 35 и сохраняет журнал и screenshot.

**Выполнено в GitHub Actions на Android 15 / API 35 (Pixel 2): PASS, 17 Android smoke assertions.** [Успешный запуск](https://github.com/funpaysell71-stack/Newpro/actions/runs/40209879504). Компиляция, lint, упаковка APK и тест эмулятора завершились успешно; журнал не содержит FATAL EXCEPTION. Главный экран просмотрен по настоящему снимку эмулятора. После визуальной проверки добавлено скругление основной карточки и исправлен порядок очистки тестовых настроек до Instrumentation.finish; повторный CI проверяет эти изменения.

Локальный программный эмулятор без KVM не завершил загрузку в доступное время и был остановлен. Подтверждённый запуск приложения — на эмуляторе GitHub Actions, не на телефоне.
